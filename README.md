#Arena +

Este é um projeto da matéria de Fábrica de Software, do curso de Sistemas de Informação e Engenharia de Software.
O Arena+ é um sistema de gerenciamento e acompanhamento de campeonatos inspirado no SofaScore. A proposta é levar a mesma facilidade de acompanhar partidas, resultados, classificações e estatísticas para o universo da robótica competitiva e do xadrez (ainda em desenvolvimento para novas modalidades).

##Funcionalidades

Campeonatos

Cadastro e gerenciamento de competições;
Definição de nome, modalidade, período e limites de participantes;
Acompanhamento do status do campeonato;
Consulta de competições em andamento e encerradas;
Organização das inscrições de equipes e participantes.

Xadrez:

Organização de campeonatos e partidas;
Consulta de confrontos e resultados;
Acompanhamento de classificações e desempenho;
Histórico de partidas e resultados anteriores;
Suporte planejado a diferentes formatos de competição, conforme as regras definidas para cada torneio.

Robótica:

Cadastro e acompanhamento de equipes;
Organização de confrontos entre equipes;
Registro de resultados das disputas;
Acompanhamento da classificação durante a competição;
Histórico de desempenho por equipe e campeonato;
Especificação de modalidades dentro da própria robótica.

##Fluxo de telas

Fluxo do Público:

Tela Inicial → Campeonatos → Detalhes do Campeonato → Partidas, Resultados e Classificação

##Fluxo do Diretor de Equipe

Login → Tela Inicial → Campeonato → Equipe → Cadastro de Atletas

##Fluxo do Organizador (em construção)

Criar campeonato: Login → Tela Inicial → Criar Campeonato
Editar campeonato: Login → Tela Inicial → Campeonatos → Editar Campeonato
Gerenciar equipes: Login → Tela Inicial → Campeonato → Equipes e Inscrições
Gerenciar partidas: Login → Tela Inicial → Campeonato → Partidas
Registrar resultados: Campeonato → Partidas → Registrar Resultado
Acompanhar competição: Login → Dashboard do Organizador
